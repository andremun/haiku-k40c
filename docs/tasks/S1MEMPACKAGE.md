# S1MEMPACKAGE: one reviewed first-batch experiment package

## Why and inputs

Depends on all five memory tasks passing and their mandatory source gates closing.
Read STATUS, S1-BATCH1-REVIEW, the final memory contract and task results, current
A7 package/guest installer/rehearsal/observer/R5 tools and ADRs 006-010.
Do not infer approval from acceptance of this plan or from A7's consumed run.

## Outputs

- A distinct finite stage, resident authority and immutable ordered phase plan.
- Stage-specific owner/client/host handshake and least-privilege read/write policy.
- Generated package/artifact/kernel/ROM/source hashes, complete effects inventory,
  gates, timing/storage bounds, evidence scopes and executable commands, all --check.
- Exact cardless job/binary rehearsal evidence and a combined implementation-review
  entry. work/S1MEMPACKAGE/{PLAN,FINDINGS,RESULT}.md; current STATUS.

## Work and prerequisites

Include fresh A7 in the combined scope: own page and same-run signed mapping
witness, both programming events, observational readback and retained lifetime.
Freeze run7 A7 phase source bytes; changes need a separate review. Remove D1/G2.
Include the discovered guest BAR1 MMIO mapping and BAR1/gk104 context scope;
BAR2 is excluded. Never reuse
an ended run's witness, driver state or consumed package/key permission.
Do not widen the old A7 role or let the client supply callbacks, addresses,
register ranges or verification flags. Bind all phases and limits into the new
stage authority. The full register/value scope must be reviewable before a yes.

Host tests exercise every phase failure and demonstrate no later effect occurs.
Check wrong-stage grants, stale evidence, repeated startup/open/reload, partial
writes, dirty/missing fault baseline and quarantine. Rehearse the exact installer
and binaries cardlessly, with defined no-card status and no grant/card permit.
Bind the exact job/binaries/kernel; changes require matching fresh evidence.
A cardless run is allowed only after the new inert/rehearsal path is prepared.
ADR 006 applies after any launcher stop; do not silently retry it.

Only full completion of all approved gates can produce the combined stage PASS.
Failure/uncertain closure retains resources, preserves primary/cleanup errors and
stops later phases. No stale-evidence fallback, clearing-to-pass or manual reset.
Intentional retention through the reviewed guest/VFIO termination is allowed;
it is not proof of general quiescence, safe live reuse or a provider retire.
The contract must close this scoped termination protocol before a runnable stage.
The guest deadline stays <=600 s. Final teardown must record host bus mastering.

## Check and review boundary

Run every generator --check, meaningful boundary/failure tests, native links,
cardless rehearsal, make check and diff check. Commit one task on main.
Present the completed batch for Claude review, then ask the user for one explicit
launch approval covering this exact combined package. Do not launch hardware in
this preparation task. Do not implement scheduler/channel/NOP or claim S1/Q7 closure.
