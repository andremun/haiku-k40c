# Task D3: GPFIFO and push-buffer encoding

Phase D: host-side algorithms and tests. This file is the whole task text. `make check` verifies the
checks named here. General rules: `AGENTS.md`. Paths to Nouveau files in
any output are relative to `reference/nouveau/`; line numbers are 1-based.

Plain C++17 built with `g++` on Ubuntu. `tests/Makefile` builds and runs
the tests. `make check` runs them.

- Why: a program gives the GPU work in two steps. It writes methods
  (header words and data words) into a push buffer, and it puts one
  entry for that buffer (address and length) into the channel's GPFIFO
  ring, then moves the put pointer. Milestone S1 is the first time the
  card accepts such an entry. This task writes the encodings and a model
  of the ring, without hardware.
- Source to read. Read only these parts, with `sed -n 'A,Bp'`:
  - `reference/mesa/src/gallium/drivers/nouveau/nvc0/nvc0_winsys.h`
    lines 41 to 90: the four header types (`NVC0_FIFO_PKHDR_SQ`, `_NI`,
    `_IL`, `_1I`) and the subchannel numbers.
  - `nouveau_dma.c` lines 72 to 110 (`nv50_dma_push`: the two words of
    a GPFIFO entry, the put pointer at USERD `0x8c`, the get pointer at
    `0x88`) and `nouveau_dma.h` lines 45 to 55.
  - `docs/hardware-model/chan.md`, the summary: word `0x4c` of the
    channel block holds the upper address bits of the ring and log2 of
    its number of entries.

- Interface, in namespace `k40::fifo`:
  - `enum class HeaderType { INCREASING, NON_INCREASING, IMMEDIATE,
    INCREASE_ONCE };` (`_SQ`, `_NI`, `_IL`, `_1I` in Mesa).
  - `uint32_t encodeHeader(HeaderType, unsigned subc, uint32_t method,
    unsigned count)`: `count` is the number of data words, or the
    13-bit data value for `IMMEDIATE`. Throws `std::invalid_argument`
    when `subc` is above 7, `method` is not a multiple of 4 or is above
    `0x7ffc`, or `count` is above `0x1fff`.
  - `struct Header { HeaderType type; unsigned subc; uint32_t method;
    unsigned count; };` `Header decodeHeader(uint32_t word)`; throws
    `std::invalid_argument` for a type that is not one of the four.
  - `class PushBuffer`: `begin(subc, method, count)` (increasing),
    `beginNonIncreasing`, `beginIncreaseOnce`, `immediate(subc, method,
    data)`, `data(uint32_t)`, `bindObject(subc, classId)` (method 0 with
    the class, as Mesa does first on each subchannel), `words()`,
    `pending()` (data words still owed), `sizeBytes()`. `data` with
    nothing pending, and a new header while data is pending, throw
    `std::logic_error`. A count of 0 throws `std::invalid_argument`.
  - `struct Method { unsigned subc; uint32_t method; uint32_t value; };`
    `std::vector<Method> decodeBuffer(const std::vector<uint32_t>&)`:
    one entry for each data word, with the method that the word goes
    to (increasing: `method + 4 * i`; non-increasing: the same method;
    increase-once: the method, then `method + 4` for all later words;
    immediate: one entry with the data value). Throws
    `std::invalid_argument` when the buffer ends inside a method.
  - `struct GpEntry { uint32_t word0, word1; };` `GpEntry
    encodeGpEntry(uint64_t addr, uint32_t lengthBytes, bool noPrefetch =
    false)`; throws `std::invalid_argument` when the address or the
    length is not a multiple of 4, the length is 0 or above
    `NV50_DMA_PUSH_MAX_LENGTH`, or the address needs more than 40 bits.
    `struct GpInfo { uint64_t addr; uint32_t lengthBytes; bool
    noPrefetch; };` `GpInfo decodeGpEntry(const GpEntry&)`.
  - Constants `kUserdGpGet`, `kUserdGpPut`, `kGpEntryBytes`.
  - `class GpFifo`: the ring. `explicit GpFifo(unsigned entries)` (a
    power of two, else `std::invalid_argument`). `push(addr,
    lengthBytes, noPrefetch = false, get = 0)` writes the entry at the
    put position, advances put with wrap-around and returns the new put
    value (the value to write to USERD `0x8c`); `get` is the GPU's get
    pointer, and when the ring is full (one slot always stays free) it
    throws `std::overflow_error` and changes nothing. `put()`,
    `entries()`, `log2Entries()`, `freeEntries(get)`, `words()` (two
    words for each entry), `ramfcWord4c(ringAddr)`.
