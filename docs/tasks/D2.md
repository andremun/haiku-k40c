# Task D2: GK104 page-table encoding

Phase D: host-side algorithms and tests. This file is the whole task text. `make check` verifies the
checks named here. General rules: `AGENTS.md`. Paths to Nouveau files in
any output are relative to `reference/nouveau/`; line numbers are 1-based.

Plain C++17 built with `g++` on Ubuntu. `tests/Makefile` builds and runs
the tests. `make check` runs them.

- Why: the GPU reads its own page tables. Every buffer of a compute job
  (command buffer, shader code, input, output) must be mapped in a GPU
  address space before the job can use it. This task writes the encoding
  of the entries and a model of an address space, without hardware.
- Source to read (Nouveau, directory `nvkm/subdev/mmu/`). Read only
  these parts, with `sed -n 'A,Bp'`:
  - `vmmgf100.c` lines 31 to 56 (`gf100_vmm_pgt_pte`: a page table
    entry is `(address >> 8) | type`), 105 to 145 (`gf100_vmm_pgd_pde`:
    a page directory entry), 236 to 265 and 308 to 328
    (`gf100_vmm_valid`: the bits of `type`; skip the compression part in
    between), 322 to 332 (`gf100_vmm_aper`), 340 to 362
    (`gf100_vmm_join_`: the two words of the instance block).
  - `vmmgk104.c` lines 24 to 51 and 67 to 80: the K40c uses
    `gk104_vmm_17` (large pages of 128 KiB, `1 << 17`; small pages of 4
    KiB). In a `nvkm_vmm_desc` line such as `{ SPT, 15, 8, 0x1000, ...
    }` the second number is the number of address bits that the level
    decodes and the third is the entry size in bytes. So: a page
    directory of `1 << 13` entries, each for 128 MiB (`1 << 27`); a
    small-page table of `1 << 15` entries; a large-page table of
    `1 << 10` entries; 40 address bits in all.
- Outputs: `src/mmu/PageTable.h`, `src/mmu/PageTable.cpp`,
  `tests/test_pagetable.cpp`, an updated `tests/Makefile`,
  `docs/mmu-encoding.md`.
- The scaffold wrote the acceptance test `tests/accept/d2_accept.cpp`

  its expected values were computed from the Nouveau code above. You
  cannot edit it.
- Interface, in namespace `k40::mmu`:
  - `enum class Target { VRAM, HOST, NCOH };`
  - `struct MapFlags { bool priv = false; bool readOnly = false; bool vol
    = false; uint8_t kind = 0; };`
  - Constants: `kVaBits`, `kSmallShift`, `kLargeShift`, `kPdeShift`,
    `kPdEntries`, `kSptEntries`, `kLptEntries`, `kPteUnmapped` (0),
    `kLptInvalid` (the value that `gk104_vmm_lpt_invalid` writes).
  - `uint64_t encodePte(uint64_t phys, Target, const MapFlags&)`.
  - `struct PageTableRef { uint64_t addr; Target target; };`
    `uint64_t encodePde(const PageTableRef* large, const PageTableRef*
    small)`: in Nouveau `pgt->pt[0]` is the large-page table and
    `pgt->pt[1]` the small-page table. A null pointer means "no table".
  - `struct VaSplit { uint32_t pde, lpte, spte; };`
    `VaSplit splitVa(uint64_t va)`.
  - `uint64_t encodeInstPdb(const PageTableRef& pd)` (the word at
    `0x200` of the instance block) and
    `uint64_t encodeInstLimit(uint64_t vaLimit)` (the word at `0x208`).
  - `class AddressSpace`: a model that keeps the page directory and the
    page tables in memory as encoded 64-bit entries.
    `explicit AddressSpace(std::function<uint64_t(uint32_t bytes)>
    alloc)`: `alloc` gives the VRAM address of a new zeroed block; the
    constructor allocates the page directory. `map(va, phys, size,
    pageShift, target, flags = {})` writes one entry for each page and
    allocates a page table when a directory entry needs one (then it
    writes the directory entry). `unmap(va, size, pageShift)`.
    `std::optional<uint64_t> translate(uint64_t va) const` walks the
    encoded entries. `pdAddr()`, `pde(index)`, `pte(pdeIndex, pageShift,
    index)` (throws `std::out_of_range` when that table does not
    exist), `tableCount()` (page tables, without the directory).
    `map` and `unmap` throw `std::invalid_argument` for a page shift
    other than 12 or 17, an address or size that is not a multiple of
    the page size, size 0, a range beyond 40 bits, a `map` over a
    mapped page and an `unmap` of a page that is not mapped; in these
    cases nothing changes.
- Not in this task: compression tags (`map->ctag`), sparse mappings, the
  MMU flush registers, and what the large-page entry must hold when
  small pages are mapped below it. Write these in the "Not covered"
  section of the document, each with the Nouveau function that does it.
