# Task C3: Subsystem hardware model

Phase C: hardware database and firmware. This file is the whole task text. `make check` verifies the
checks named here. General rules: `AGENTS.md`. Paths to Nouveau files in
any output are relative to `reference/nouveau/`; line numbers are 1-based.

- Outputs: `docs/hardware-model/<name>.md` for pci, bars, mmio, mc,
  fb-vram, instmem, bar, mmu, fifo, channel, gpfifo, runlist, pbdma, gr,
  falcon-firmware. Each has: purpose, Nouveau files, registers,
  dependencies, and sections `KNOWN`, `INFERRED`, `UNKNOWN`.
- Check: files exist, have the three sections, cite existing files.
- Split (2026-10-11): this task is done in parts, each with its own text
  and checks. `C3a`: mc, bar, imem, mmu, fb, top. `C3b`: privring, ltc,
  timer. The FIFO and GR parts follow. The output of each part is
  `analysis/hwmodel/<subsystem>.json` and a generated
  `docs/hardware-model/<subsystem>.md`.
