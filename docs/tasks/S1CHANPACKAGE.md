# S1CHANPACKAGE: freeze and rehearse the combined NOP package

## Why and inputs

After S1CHANSUBMIT. Read S1-CHANNEL-CONTRACT, all new generated inventories and
current guarded launcher/observer/rehearsal interfaces. Read HAIKU_BUILD_TEST
before guest changes. Preserve raw past captures and all consumed markers.

## Outputs

- One immutable unconsumed combined A7/memory/channel package and public manifest.
- Exact host-check/build-check commands, artifact/kernel/ROM hashes and job binding.
- Exact cardless complete-job rehearsal and deterministic evidence validator.
- docs/S1-CHANNEL-REVIEW-PACKAGE.md for Claude and a later one-run user decision.

## Work and checks

No card launch. Keep fixed 04:00.0, VFIO/IOMMU/isolation rechecks, one guest,
disposable overlay, live R5/observer, independent 600-second watchdog and write-once
incremental evidence. Bind all subphases/roles/keys/owner transitions to one plan.
List all inherited A7 and new writes, mappings and source-derived expressions.
Compute total per-phase wait/output/closure budgets inside the unchanged deadline.
Include omitted Linux writes and reasons, raw fault criteria and final bus-master check.

Rehearse identical job generator/binaries cardless, with no VFIO/card permit/grants.
Use unwatched staging, size/hash/same-inode rename checks and final-name loads.
Specify exact no-card refusal/open status, load counts and one-shot retention.
Bind the rehearsal to the job and all artifacts. Any launcher stop requires a
user decision before retry under ADR 006, including a cardless parser false alarm.

Test host grants with inert fixtures, evidence tampering, missing phase/closure,
consumption/replay and S1-overclaim rejection. Run make check and all package checks.
Stop at the review handoff. Claude acceptance and one explicit user yes for the
whole exact combined stage are required before any physical launch.

## Shared constraints

Read STATUS and this task only, then the named contract/source inputs.
Do not read tools/check_repo.py, tests/accept/ or unrelated task files.
Write PLAN before large work, update FINDINGS, and write RESULT (at most 40 lines).
Generate JSON with a deterministic tool and no-write --check. Record consulted
Nouveau files in licensing.md. Run make check before one commit on main.
No push, root, hardware run, reset, other card, host binding or consumed-marker change.
A7 phase source/client/helper bytes stay frozen to run7. No BAR2 or host payload DMA.
